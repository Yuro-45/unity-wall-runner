# Unity Wall Runner

A first-person wall-running time trial built in **Unity 6** (6000.3, URP) for a Week 2 portfolio
assignment on movement mechanics: surface normals, vector projection, raycasts and state machines.

The goal is a short parkour course in the style of Titanfall and Mirror's Edge: run along walls,
jump between them, slide, mantle, and race a ghost of your best time.

> Status: work in progress. The first-person controller is done (move, sprint, jump, coyote time,
> jump buffering). Wall running is next.

## Controls

| Input | Action |
|---|---|
| WASD | Move |
| Mouse | Look |
| Left Shift | Sprint |
| Space | Jump |
| Left Ctrl / C | Crouch (used by the slide, not implemented yet) |

## How the player works

The player is a `CharacterController` driven by a small state machine. `PlayerController` owns the
velocity and moves the body; the active state decides what the velocity should be each frame.

| Script | Role |
|---|---|
| `PlayerInputReader` | The only script that touches the Input System; exposes `Move`, `Look`, `JumpPressed` and so on |
| `PlayerLook` | Mouse look: turns the body left/right, tilts the camera holder up/down |
| `MovementSettings` | ScriptableObject holding every tuning value (speeds, gravity, jump height, timers) |
| `PlayerController` | Runs the current state, then moves the body by `Velocity` |
| `PlayerState` | Base class for states: `Enter`, `Exit`, `Tick` |
| `GroundState` | Walk and sprint, stick to slopes, jump |
| `AirState` | Air steering that keeps momentum, gravity, landing |
| `PlayerDebugHud` | On-screen state and speed readout for tuning |

**Jump feel**

- **Coyote time:** a jump still works for 0.12 s after running off a ledge.
- **Jump buffering:** a jump pressed up to 0.12 s before landing fires on touchdown.
- Jump speed is derived from the height you want: `v = sqrt(2 * gravity * jumpHeight)`.

## Test room: `L_TestRoom`

A greybox room with one labelled station per mechanic. Every surface has a 1 m grid.
Orange walls are on the `Runnable` layer; blue is platforms and props; dark grey is not runnable.

| # | Station | What it tests |
|---|---|---|
| 1 | Jump gaps | Platforms with gaps of 2 to 6 m |
| 2 | Heights | Blocks from 0.5 to 3 m, for jump height and mantling |
| 3 | Wall run | A wall on each side, plus a wall that is not runnable |
| 4 | Wall chain | A 30 m gap crossable only by chaining three walls |
| 5 | Angles and corners | Angled walls, an inside corner, a pillar |
| 6 | Slide | A ramp for speed, then a 1.2 m gap |
| 7 | Wall-jump climb | Two 14 m walls, 4 m apart |
| 8 | Curved wall | A 120 degree arc of short segments |

The room is generated by an editor script and can be rebuilt any time from the menu:
**WallRunner > Rebuild Test Room**. It replaces everything under the `Environment` object.
